The whole internet, in one word: **enshittification**.

Every platform starts useful, then slowly trades its users for advertisers,
its advertisers for shareholders, and its soul for engagement metrics — until
the feed you loved is an ad-stuffed slot machine that still calls itself
"connecting people". One word, no explanation needed: funny because it is
true, true because it is the whole internet.

## Run it

```sh
python3 main.py
```

Writes the word to `/output/entry.txt` (override with `MAKEFUN_OUTPUT` for a
local run).
